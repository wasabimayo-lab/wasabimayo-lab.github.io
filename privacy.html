DayDock 개인정보처리방침

본 문서는 DayDock Windows 앱과 이 안내 사이트에서 다루는 데이터에 관한 설명입니다.

접근하는 정보와 목적

  • Google Calendar 목록: 동기화할 캘린더를 표시하고 구분하기 위해 사용합니다.
  • 일정의 제목·내용·시간·장소·반복·알림 등: 달력 표시, 검색, 편집, 알림 및 동기화에 사용합니다.
  • Google Tasks 목록과 할 일: 목록 표시, 완료 상태·마감일 관리 및 동기화에 사용합니다.
  • OAuth 토큰과 클라이언트 설정: 사용자가 승인한 Google API 연결을 유지하는 데 사용합니다. 앱은 Google 비밀번호를 입력받거나 저장하지 않습니다.

Google 권한

현재 앱은 calendar.calendarlist.readonly, calendar.events, tasks 범위를 요청합니다. 일정·할 일의 생성·수정·삭제 권한이 포함되며, 실제 전송은 앱의 캘린더별 읽기 전용·편집 허용 설정과 동기화 정책에 따릅니다. Google의 계정 승인 화면에서 허용 여부를 결정할 수 있습니다.

보관과 전송

일정·할 일 캐시, 설정, 변경 대기열, 기록과 백업은 앱 data 폴더 및 사용자가 만든 로컬 백업에 보관될 수 있습니다. OAuth 토큰과 연결 자격 정보는 Windows 현재 사용자에 연결된 DPAPI로 보호해 credentials 폴더에 저장합니다. 일정 캐시 전체를 암호화 저장한다고 주장하지는 않습니다.

동기화 데이터는 앱에서 해당 서비스의 HTTPS API로 직접 전송합니다. DayDock은 자체 일정 중계 서버나 광고 서버를 운영하지 않으며, Google 사용자 데이터를 광고·판매·제3자 추적 목적으로 사용하지 않습니다. 별도로 설정한 외부 캘린더 연결은 사용자가 지정한 공급자와 통신할 수 있습니다.

Google API에서 받은 정보의 이용과 전송은 Google API Services User Data Policy와 Limited Use 요건을 따릅니다. 사용자가 화면에 표시·수정·동기화하도록 요청한 기능에 필요한 범위에서 정보를 처리합니다.

보관 기간과 연결 해제

로컬 자료는 사용자가 삭제할 때까지 남을 수 있습니다. 앱에서 계정 연결을 해제하면 이 PC의 해당 토큰을 제거하지만 로컬 일정과 대기열은 보존합니다. Google 계정의 서드 파티 연결 관리에서도 권한을 철회할 수 있습니다. 로컬 기록과 백업까지 지우려면 앱을 종료한 뒤 보관한 자료를 직접 정리해야 합니다.

안내 사이트와 진단 정보

이 안내 사이트는 로그인·일정 입력 폼이나 자체 분석 스크립트를 포함하지 않습니다. 사이트 호스팅 제공자는 운영을 위한 일반적인 접속 정보를 처리할 수 있습니다. 앱의 오류 진단 정보는 로컬 로그에 기록될 수 있으며 이 안내 사이트로 보내지 않습니다.
